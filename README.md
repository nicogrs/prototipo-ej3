# Copiloto de imprevistos

Prototipo navegable (mobile-first) de un acompañante digital de viaje: cuando algo se sale del plan, le muestra al viajero qué pasó, en qué paso está, qué sigue y cuánto falta.

Escenario: conexión perdida de madrugada en Bogotá (03:05), volviendo de Nueva York a Montevideo.

> Los datos (vuelos, hotel, aerolínea) son de ejemplo y el módulo de IA es representativo: responde con un guion basado en el itinerario, sin conexión a ningún modelo.
